# Лабораторная работа 2

**Тема:** Исследовательский анализ данных. Постановка гипотез. Категориальные данные.

**Сложность:** Medium (общая часть + самостоятельная часть).

## Что реализовано
1) **Общая часть (mpg):**
- Загрузка `mpg` через `sns.load_dataset('mpg')`
- EDA по числовым и категориальным признакам
- 2 статистические гипотезы с обоснованием критериев
- Кодирование категорий (OneHot, Label)
- Корреляция признаков и целевого столбца
- Градиентный и стохастический градиентный спуск (mpg ~ horsepower)

2) **Самостоятельная часть (вариант, F1 SQLite):**
- Объединение таблиц из БД Formula 1
- EDA по числовым и категориальным признакам
- 2 статистические гипотезы с обоснованием критериев
- Кодирование категорий (OneHot, Label)
- Корреляция признаков и целевого столбца
- Градиентный и стохастический градиентный спуск (points ~ grid)
