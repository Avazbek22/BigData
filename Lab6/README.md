# Лабораторная работа 6.1

**Тема:** Обработка естественного языка и классификация текста.

**Сложность:** Well-done (общая + самостоятельная часть).

## Что реализовано
- Сбор/загрузка 10+ песен (используется готовый файл `kanye_lyrics.txt`)
- Препроцессинг: нижний регистр, пунктуация, токенизация, лемматизация, стемминг
- Удаление стоп-слов
- TF-IDF и топ-слова
- WordCloud
- Word2Vec + поиск похожих слов
- t-SNE визуализация 15 частых слов
- Дополнено стихами + классификация (KNN, SVC, RandomForest, LogisticRegression)

## Запуск
```bash
py -3 Lab6\Lab6\Lab6.py
```
